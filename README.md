# Hadal OS packages

The pacman repository of [Hadal OS](https://github.com/Diffamas/hadal-os-packages): the built
packages, their signatures and the repository database. Installed Hadal OS
systems follow it on their own; there is nothing to do by hand.

```
[hadal]
SigLevel = Required DatabaseOptional
Server = https://raw.githubusercontent.com/Diffamas/hadal-os-packages/main/$arch
```
